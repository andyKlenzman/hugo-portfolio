Lightbender was a mixed-media performance I presented at a local open-mic event, exploring how technology can merge with art.  

I built a system using Python’s OpenCV computer vision library together with an Arduino-driven LED strip. The system tracked dance movements and translated them into dynamic light patterns, creating a visual display that moved in sync with live music.

### Behind the Technology

To make this possible, I combined real-time computer vision with low-latency LED programming. The webcam captured motion data, which was processed in Python to extract movement and rhythm. This data was then transmitted to the Arduino, which updated the LEDs instantly, ensuring the lights were responsive to dance gestures.
